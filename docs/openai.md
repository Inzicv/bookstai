# OpenAI

OpenAI n'est pas une dépendance obligatoire du mode local BookstAI.

## Position actuelle

- le provider par défaut est `mock`;
- OpenAI est une étape future pour le texte uniquement;
- aucune intégration OpenAI n'est activée automatiquement;
- la clé API sera gérée côté backend quand cette étape sera ajoutée.

## Ce qui n'est pas le cas aujourd'hui

- Langflow n'est plus une dépendance active;
- OpenAI n'est pas requis pour lancer l'application locale;
- Song ne génère pas d'image;
- aucun workflow ne doit dépendre d'OpenAI pour fonctionner en `mock`.
